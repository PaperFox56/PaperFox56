### About me
I am Michael, a first-year engineering student. I'm passionate about hardware and low-level systems, frequently building emulators and virtual machines for fun. 

I also enjoy implementing high-level projects like inference engines (Prolog) and video games. While my current repo list focuses on the former, I am also deeply interested in data science and machine learning.

I live in the CLI and am currently developing tools for the terminal, such as [Teye](https://github.com/PaperFox56/teye) (a bitmap rendering tool) and [Femto](https://github.com/PaperFox56/Femto) (a terminal text editor). I'm a self-described [Hacker-poet](https://josephg.com/blog/3-tribes/), currently learning functional programming with Haskell.
